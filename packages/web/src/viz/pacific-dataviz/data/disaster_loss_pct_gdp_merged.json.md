# disaster_loss_pct_gdp_merged.json

Direct economic loss from disasters as % of GDP, per country per year (~2000–2024), merging UNDRR Sendai reporting with EM-DAT damage gap fills (UNDRR primary; EM-DAT fills zeros/missing years). 15 countries, incl. 3 added entirely by EM-DAT (AS, GU, NU).

- **Primary source (UNDRR):** indicator `VC_DSR_AALT` (direct economic loss, SDG Sendai) via SPC dataflow `DF_SDG_11` v3.0 ([dataset page](https://sdd.spc.int/dataset/df_sdg_11)) from the [SPC Pacific Data Hub](https://pacificdata.org/) — [raw CSV](https://github.com/codyrushing/crushingviz/blob/main/packages/data/pacific-dataviz-challenge-2026/SPC,DF_SDG_11,3.0,complete,2026-06-14%2018-16-49.csv). Unit bug (mixed `USD` / `USD_MILLIONS`) normalized to USD by [analysis/extract_disaster_loss.py](https://github.com/codyrushing/crushingviz/blob/main/packages/data/pacific-dataviz-challenge-2026/analysis/extract_disaster_loss.py); joined to GDP by [analysis/extract_economic.py](https://github.com/codyrushing/crushingviz/blob/main/packages/data/pacific-dataviz-challenge-2026/analysis/extract_economic.py) ([derived/disaster_loss_pct_gdp.json](https://github.com/codyrushing/crushingviz/blob/main/packages/data/pacific-dataviz-challenge-2026/derived/disaster_loss_pct_gdp.json)).
- **Gap-fill source (EM-DAT):** [EM-DAT](https://www.emdat.be/) HDX [Country Profiles](https://data.humdata.org/dataset/emdat-country-profiles) damage column, via [derived/disaster_emdat_by_type.json](https://github.com/codyrushing/crushingviz/blob/main/packages/data/pacific-dataviz-challenge-2026/derived/disaster_emdat_by_type.json).
- **GDP denominator:** SPC `DF_NATIONAL_ACCOUNTS` via [derived/gdp_by_country.json](https://github.com/codyrushing/crushingviz/blob/main/packages/data/pacific-dataviz-challenge-2026/derived/gdp_by_country.json).
- **Processing script:** [analysis/merge_emdat_loss.py](https://github.com/codyrushing/crushingviz/blob/main/packages/data/pacific-dataviz-challenge-2026/analysis/merge_emdat_loss.py) → [derived/disaster_loss_pct_gdp_merged.json](https://github.com/codyrushing/crushingviz/blob/main/packages/data/pacific-dataviz-challenge-2026/derived/disaster_loss_pct_gdp_merged.json).
- **Caveat:** losses are nominal USD (not inflation-adjusted); pre-2005 fills are normalized against each country's 2005 GDP (flagged in the file's `pre_2005_note`).
