# countries.json

Lookup table of the 22 Pacific Island Countries and Territories (PICTs) used throughout this visualization: country code → display name + flag emoji.

- **Created:** hand-authored (no processing script); country codes follow the `GEO_PICT` ISO-2 codes used by the [SPC Pacific Data Hub](https://pacificdata.org/).
- **No external dataset is reproduced** — only codes, names, and flag emoji.
