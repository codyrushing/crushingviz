# disaster_affected_merged.json

People directly affected by disasters, per country per year (~2000–2026), merging UNDRR Sendai reporting with EM-DAT gap fills. Every value is tagged with its source (`undrr` / `emdat`).

- **Primary source (UNDRR):** indicator `VC_DSR_AFFCT` (directly affected persons, SDG 1.5.1 / 11.5.1, Sendai Framework / DesInventar) via SPC dataflow `DF_SDG_11` v3.0 ([dataset page](https://sdd.spc.int/dataset/df_sdg_11)) from the [SPC Pacific Data Hub](https://pacificdata.org/) — [raw CSV](https://github.com/codyrushing/crushingviz/blob/main/packages/data/pacific-dataviz-challenge-2026/SPC,DF_SDG_11,3.0,complete,2026-06-14%2018-16-49.csv), extracted by [analysis/extract_affected.py](https://github.com/codyrushing/crushingviz/blob/main/packages/data/pacific-dataviz-challenge-2026/analysis/extract_affected.py) into [derived/disaster_affected_by_country.json](https://github.com/codyrushing/crushingviz/blob/main/packages/data/pacific-dataviz-challenge-2026/derived/disaster_affected_by_country.json).
- **Gap-fill source (EM-DAT):** [EM-DAT](https://www.emdat.be/) (CRED/UCLouvain) HDX [Country Profiles](https://data.humdata.org/dataset/emdat-country-profiles) (2000–2026) — [raw/emdat-country-profiles.xlsx](https://github.com/codyrushing/crushingviz/blob/main/packages/data/pacific-dataviz-challenge-2026/raw/emdat-country-profiles.xlsx).
- **Processing script:** [analysis/merge_emdat.py](https://github.com/codyrushing/crushingviz/blob/main/packages/data/pacific-dataviz-challenge-2026/analysis/merge_emdat.py) — UNDRR non-zero values kept as primary; EM-DAT replaces zeros (treated as reporting gaps) and supplies missing years.
- **Upstream derived file:** [derived/disaster_affected_merged.json](https://github.com/codyrushing/crushingviz/blob/main/packages/data/pacific-dataviz-challenge-2026/derived/disaster_affected_merged.json).
- **Caveat:** "affected" is counted slightly differently by UNDRR (directly affected) vs EM-DAT (injured + homeless + affected); totals are lower-bound estimates.
